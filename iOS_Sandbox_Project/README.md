# Интерактивная песочница iOS 18 для Android (iOS Sandbox)
### Практический продукт для индивидуального проекта студента
**Автор:** Юсупов Оятуллох Кудратджонович, гр. 100/1  
**Тема:** «Сравнение операционных систем Android и iOS» (ГБПОУ НСО «НППК»)

---

## Что внутри продукта:
1. **Dynamic Island:** интерактивный «Островок» сверху — при тапе плавно раскрывается с анимацией плеера и визуализатора волн.
2. **Экран блокировки (Lock Screen):** фирменные крупные часы iOS, дата на русском, фонарик, камера, свайп вверх с разблокировкой.
3. **Рабочий стол (SpringBoard):** сетка иконок iOS (squircle), размытый док (Frosted Glass), виджет погоды и аналитики.
4. **Центр управления (Control Center):** свайп сверху справа — плавные сенсорные ползунки яркости (реально меняют яркость экрана) и громкости, переключатели связи.
5. **Рабочие мини-приложения:**
   * **Калькулятор:** точная физика и математика калькулятора Apple.
   * **Настройки:** списки, тумблеры, пункт «Об этом устройстве» с указанием студента и параметров хост-системы Android.
   * **Заметки:** добавление и просмотр записей.
   * **Тест подбора ОС:** интерактивный опросник на 5 вопросов с расчетом процентов совместимости.
6. 🔥 **Киллер-фича: Приложение «Сравнение ОС»:**
   * Наглядное сопоставление элементов управления: тумблер Apple против Material 3.
   * Интерактивная демонстрация диалоговых окон: как открывается алерт в iOS (стекло с кнопками по сетке) и как в Android (карточка Material You).
   * Таблица сравнения ядер (Linux vs Darwin) и сред исполнения (ART vs Нативный машинный код).

## Как запустить на компьютере:
Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Yandex). На широком экране приложение отображается в виде реалистичного макета iPhone 16 Pro.

---

## Как запустить на телефоне (Android):
1. Скопируйте папку на телефон или откройте через любой локальный веб-сервер.
2. Либо залейте файлы на бесплатный хостинг (GitHub Pages, Vercel или Netlify — перетащив папку мышкой).
3. Откройте ссылку в браузере Chrome на телефоне.
4. Нажмите три точки в Chrome -> **«Установить приложение»** (или «Добавить на главный экран»).
5. Приложение установится как автономное (PWA), появится иконка, и оно будет открываться на весь экран без адресной строки браузера — как настоящая нативная система!

## Как собрать файл .APK:
1. Загрузите этот проект на свой GitHub (или залейте на Netlify/Vercel).
2. Зайдите на официальный сервис Microsoft: **https://www.pwabuilder.com/**
3. Вставьте ссылку на ваш сайт.
4. Нажмите **«Package for Android»** -> **«Download APK»**.
5. Сервис автоматически сгенерирует готовый файл `.apk`!
